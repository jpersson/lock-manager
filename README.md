# lock-manager

Home Assistant app (add-on) repository. [Lock Manager](lock-manager/) manages
keypad users for Zigbee2MQTT locks: per-lock user lists, encrypted PIN storage,
one-action PIN applies to one or more locks, and notifications plus an activity
log for keypad lock/unlock events.

## Add this repository to Home Assistant

Settings → Apps → App Store → ⋮ → Repositories, then add this repository's URL.

## Apps

- [**Lock Manager**](lock-manager/) — keypad user management for Zigbee2MQTT locks
